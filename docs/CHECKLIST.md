# Lista de control antes de entregar

## Etapa 1 · HTML
- [ ] Uso `header`, `nav`, `main`, `section`, `article`, `footer`
- [ ] Un único `h1` por página y los títulos no saltean niveles
- [ ] El menú conecta todas las pantallas y funciona en todas
- [ ] Hay formularios con `label` asociado (`for` + `id`) y tipos `email`, `number`, `date`
- [ ] Todas las imágenes tienen `alt` descriptivo

## Etapa 2 · CSS
- [ ] Colores y tipografías definidos como variables en `:root`
- [ ] Maquetación con Flexbox y Grid (sin `position` forzado)
- [ ] Al menos un `@media` (hay dos: 48rem y 64rem)
- [ ] `:hover` y `:focus` en enlaces, botones y campos
- [ ] Transiciones y componentes reutilizables (`.btn`, `.card`, `.alert`, `.badge`)

## Etapa 3 · JavaScript (mínimo 2; hay 6)
- [ ] Validación de formulario · [ ] Menú hamburguesa · [ ] Contenido desde datos
- [ ] Búsqueda/filtro · [ ] Modo claro/oscuro · [ ] Motor de anonimización

## Etapa 4 · Verificar
- [ ] Contraste revisado (DevTools → inspeccionar un texto → ver la relación de contraste)
- [ ] Recorrí todo con Tab y siempre se ve el foco
- [ ] Apliqué mejoras del testeo de la Ejercitación 1.1
- [ ] Lighthouse ejecutado y puntajes anotados en el README

## Etapa 5 · Publicar
- [ ] Repositorio en GitHub con **varios commits** (no uno solo)
- [ ] Sitio publicado en GitHub Pages y el enlace funciona
- [ ] README con nombre, integrantes, descripción, enlace al sitio y a Figma

## Control final de la consigna
- [ ] Se ve bien en celular y en computadora
- [ ] Todos los enlaces del menú funcionan; no hay imágenes rotas
- [ ] Los formularios muestran mensajes claros ante datos incorrectos
- [ ] No hay errores en la consola (F12 → Console)
- [ ] El sitio publicado coincide con la última versión del repositorio
- [ ] Puedo explicar cada parte del código (ver preguntas en la guía, sección 10)

1. Enlace al repositorio · 2. Enlace al sitio · 3. Presentación «Del diseño al código» (`docs/PRESENTACION.md`)
